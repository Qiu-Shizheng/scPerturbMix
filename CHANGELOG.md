# Changelog

## 0.5.0 — 2026-11-01

- Mouse cytokine-response checkpoint with 83 registered conditions and a `predict_conditions` Python interface.
- Automatic condition-format detection in the prediction CLI, preserving the experimental dose units.
- Expanded benchmark comparisons, including Geneformer V1/V2, biolord and classical estimators across eleven matched task groups.
- External cytokine validation, component comparisons and dataset guides covering twelve experiments from eleven studies.

## 0.4.0 — 2026-10-30

- Public scPerturbMix package with CPU prediction and fitting commands.
- Fitted response models, programme-response inference and reproducible examples.
- Unified benchmark comparisons, dataset descriptions and task guidance.
- Optional PyTorch reference models and H5AD input support.
