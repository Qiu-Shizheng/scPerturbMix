# scPerturbMix 0.5.1

This release provides CPU prediction and fitting interfaces for single-cell perturbation responses.

- Run the included [Immune Dictionary example](examples/immune_dictionary/README.md) to predict and score 438 observed mouse cytokine-response conditions.
- Use six fitted checkpoints for drug-response, expression and mouse cytokine-response prediction.
- Fit gene-response and programme-response models to your own matched treated and untreated profiles.
- Compare methods using the [complete benchmark tables](docs/benchmark_comparison.md), with dataset descriptions and experimental input requirements.
- Inspect the [CellFlow interferon-response comparison](docs/cellflow_benchmark.md), including both output conventions, donor-level results and distribution-metric sensitivity.
- Follow the [user guide](docs/user_guide.md) for installation, real-data prediction, model fitting and troubleshooting.
